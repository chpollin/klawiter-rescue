      What a decision means

      Every value was read from the print volumes by a rule and is bound to its passage in the entry text. A decision says whether that value is right in its entry: right, wrong (with the right passage, selected in the entry text or typed into the passage field, or marked as a value that should not exist) or unsure. A value inherited from a heading or header can only be marked as wrong, with the right value in the note, because its passage lies in another record. A value the rules did not read can be added, and an object that begins or ends in the wrong place can be flagged. Decisions are stored by the local review server beside the data; a later decision on the same value replaces the earlier one, and a decision no longer applies once a rebuild changes its value.

      What the review sample measures

      The review sample is a frozen draw of objects from entries that rule development had not seen, stratified by volume and part. Only objects marked complete count. They give the share of right values per volume, type and field, and the values the rules missed. Reviewers see the rule values while deciding, so the figure is acceptance after inspection, not a blind annotation. Decisions on objects outside the sample are kept as development reviews and enter no measurement.

      Records that are no entries

      Index entries hold a term and the addresses the index gives for it, each linked to the entry it names. Front matter and tail passages are the other pages of the volumes, kept word for word as passages. Neither belongs to the review.

      Recording decisions

      Decisions are shown and recorded only while the page is served by the review server of the print strand (review_server.py). Served otherwise, the view is read only and shows no review state beyond what the last export recorded.

      Questions

      A question records a problem larger than one value: a printed convention whose meaning is unknown, a reading error that recurs, a case the data model cannot hold. It names the objects it concerns, the kind of problem and who can settle it. Rules and LLM agents may ask and propose an answer; only a person answers. Press Q on an object to ask about it or to add it to an open question.

      Scope

      The view shows the main volume of 1991, Addendum I of 1999 and the working file of Addendum II, with their indexes, front matter and tails. It runs only on this computer, because the rights to the print volumes are unresolved.
