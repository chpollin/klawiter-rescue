klawiter:sourceRevision

Property — source revision

The wiki revision an entry is published from where it departs from the page's latest revision, because the wiki's automatic Redirect fixer account had overwritten the page with an unrelated redirect. The value names the revision, its author and date, its text identifier, the decision that restored it and the reason.
