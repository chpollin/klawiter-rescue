klawiter:ruleGaps

Property — rule gaps

The flat fields of an entry that a stated rule left empty although the source page carries text there, each with the field and the rule. A rule gap is no source gap: statement-bindings empties a place, publisher or translator that no position of the page's first statement binds to the described publication, damaged-letter a value that kept a letter whose bytes were lost before the dump was written.
