klawiter:printAddress

Property — print address

Normalized print address: section letter, A1 or A2 for an addendum, and entry number with an optional letter suffix or range, such as F 47, HA1 34, FA1 24a or G 796-798; an unnumbered Addendum II address is its code alone, such as LA2.
