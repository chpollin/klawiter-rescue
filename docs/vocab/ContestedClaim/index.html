klawiter:ContestedClaim

Class — Contested Claim

A disputed identity assertion that stays part of the final dataset with its exact source evidence, all competing interpretations, the review trail, and an open decision status. Two evidence kinds exist: edition work-binding claims carry a Web Annotation offset selector, authority reconciliation claims carry source-occurrence evidence.
