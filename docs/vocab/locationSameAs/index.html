klawiter:locationSameAs

Property — location same as

Wikidata URI of the primary publication location, for example http://www.wikidata.org/entity/Q90 for Paris. In the published RDF the link sits as schema:sameAs on the Place node; this property remains for flat projections. A dedicated property, not schema:sameAs on the work, which would conflate the work with the place.
