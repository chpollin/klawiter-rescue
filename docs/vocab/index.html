Klawiter Bibliography Vocabulary

Namespace for the Stefan Zweig Bibliography (Klawiter) Linked Data project

Namespace URI: https://chpollin.github.io/klawiter-rescue/vocab/
Preferred prefix: klawiter:
Version: 3.1 (gate evidence terms, RDF resource modeling, claim properties renamed to hasContestedClaim and hasReviewAction)

Domain vocabulary for the Stefan Zweig Bibliography (Klawiter) Linked Data project. It extends Schema.org and Dublin Core with domain-specific entry types, classifications, MediaWiki source metadata, and the evidence terms of the Work/Edition and reconciliation gates. Standard bibliographic properties use Schema.org, provenance and citation use Dublin Core and PROV, terms without an equivalent in existing vocabularies are defined here. The namespace also hosts instance identifier sub-spaces (entry/, work/, edition/, annotation/, carrier/, claim/, review/, agent/, plan/, dataset/, person/, publisher/, organization/, place/, location/, sourceText/, evidence/); instance identifiers always contain a slash and are disjoint from term names, which never do. Every term is dereferenceable as vocab/<TermName>/.

Machine-readable

This page is generated from the Turtle register, so it lists every term the ontology defines. Both serializations carry the same content:

  • klawiter.ttl — Turtle (RDFS / SKOS)
  • klawiter.vocab.jsonld — JSON-LD

Every term below is dereferenceable at https://chpollin.github.io/klawiter-rescue/vocab/TermName/.

Vocabulary Design

Each bibliographic entry uses multiple vocabularies via JSON-LD @context:

  • schema: Standard bibliographic fields
  • dcterms: Bibliographic citation and provenance
  • klawiter: Domain types, classifications, source metadata, and gate evidence (defined below)

Entry type classes

TermKindDefinition
klawiter:FictionEntryClassNovels, novellas, short stories by Stefan Zweig.
klawiter:EssayEntryClassEssays, articles, reviews.
klawiter:PoetryEntryClassIndividual poems and poetry collections.
klawiter:DramaEntryClassPlays, libretti, dramatic works.
klawiter:FilmEntryClassFilm adaptations, operas, multimedia.
klawiter:CorrespondenceEntryClassBibliographic records describing letters and correspondence. schema:Message is the closest Schema.org type; the record describes correspondence, it is not the message itself, so only a close match is asserted and the emitted type is schema:CreativeWork.
klawiter:CollectedWorksEntryClassAnthologies, selected and collected works.
klawiter:SecondaryLiteratureEntryClassScholarship about Stefan Zweig.
klawiter:HistoricalStudyEntryClassMonographs, dissertations, academic studies.
klawiter:TranslationEntryClassTranslations by Zweig of other authors' works.
klawiter:ForewordEntryClassForewords, afterwords, editorial contributions.
klawiter:SymposiumEntryClassBibliographic records describing symposia, exhibitions, and conferences about Zweig. The record is the description that carries publication properties; the event itself is only a close match, so schema:Event is not emitted as a direct type.
klawiter:DramaticReadingEntryClassDramatic readings and staged performances.
klawiter:NewspaperEntryClassNewspaper articles.
klawiter:RedirectEntryClassAlias pointing to another entry, from MediaWiki. No Schema.org equivalent is mapped.
klawiter:OtherEntryClassUnclassifiable entries.
klawiter:WikiInfrastructurePageClassNon-bibliographic MediaWiki page preserved as source structure: category, template, help, file, and system pages. Never typed as a bibliographic work and never carries a bibliographic citation.

Gate evidence classes

TermKindDefinition
klawiter:ContestedClaimClassA disputed identity assertion that stays part of the final dataset with its exact source evidence, all competing interpretations, the review trail, and an open decision status. Two evidence kinds exist: edition work-binding claims carry a Web Annotation offset selector, authority reconciliation claims carry source-occurrence evidence.
klawiter:ClaimInterpretationClassOne competing reading of a contested claim, optionally proposing an object. The fail-closed alternative proposes no object.
klawiter:ReviewActionClassOne step of the review trail on a claim or edition: who reviewed, on what basis, with what outcome.
klawiter:WorkIdentityCandidateClassA candidate independent work identity proposed by a contested work-binding claim, kept unresolved until an authorized decision.

Domain-specific entry properties

TermKindDefinition
klawiter:entryTypePropertyClassification key: fiction, essay, poetry, drama, film, correspondence, collected-works, secondary-literature, historical-study, translation, foreword, symposium, dramatic-reading, newspaper, redirect, other, plus the wiki infrastructure namespaces category, mediawiki, template, help, file.
klawiter:timePeriodPropertyHistorical period: pre-zweig (before 1881), lifetime (1881-1942), post-wwii (1943-1980), late-20c (1981-2000), contemporary (2001 onward).
klawiter:categoriesPropertyMediaWiki categories from the original bibliography wiki, normalized like MediaWiki titles (sort keys stripped).
klawiter:contentItemsPropertyTable of contents for collected works.
klawiter:mainCategoryPropertyPrimary category used for entry type classification.
klawiter:originalTitlePropertyOriginal-language title, when the entry title differs, for example for translations.
klawiter:languageNamePropertyHuman-readable language name as the source states it, for example German, Chinese. The BCP-47 code lives in schema:inLanguage.
klawiter:languageCodePropertyISO 639-1 language code. Superseded in the published datasets: schema:inLanguage now carries the code. Retained for older exports.
klawiter:allYearsPropertyAll years mentioned in the entry, when multiple editions or reprints are listed.
klawiter:allLocationsPropertyAll publication locations when multiple are mentioned.
klawiter:locationSameAsPropertyWikidata URI of the primary publication location, for example http://www.wikidata.org/entity/Q90 for Paris. In the published RDF the link sits as schema:sameAs on the Place node; this property remains for flat projections. A dedicated property, not schema:sameAs on the work, which would conflate the work with the place.
klawiter:seeAlsoTextPropertyUnresolvable See-reference preserved as written: the referenced bibliography page was never created (a red link in the source wiki). Resolved references use dcterms:relation with entry IRIs.
klawiter:reprintsPropertyReferences to reprint editions.

Alignment Notes

Stefan Zweig Digital

The Stefan Zweig Digital project at the Stefan Zweig Centre Salzburg (University of Salzburg) uses CIDOC-CRM for cultural heritage modeling. A future alignment between this vocabulary and CIDOC-CRM / LRMoo is planned as a separate research project to enable cross-project linked data queries.

Wikidata

Stefan Zweig is identified as Q78491 in Wikidata. Publication places, translators, and publishers are reconciled against Wikidata under Gate 2; only a decided and evidenced match becomes a published link, a disputed one stays a klawiter:ContestedClaim.
