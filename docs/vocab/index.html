Klawiter Bibliography Vocabulary

Namespace for the Stefan Zweig Bibliography (Klawiter) Linked Data project

Namespace URI: https://chpollin.github.io/klawiter-rescue/vocab/
Preferred prefix: klawiter:
Version: 2.0 (Schema.org blend)
Last updated: 2026-03-29

This vocabulary extends Schema.org and Dublin Core with domain-specific terms for the Klawiter Stefan Zweig bibliography. Standard bibliographic properties use Schema.org; provenance and citation use Dublin Core; terms without equivalents in existing vocabularies are defined here.

Machine-readable

The vocabulary defined on this page is also available as a machine-readable ontology (RDFS classes and properties, with SKOS and OWL declarations). Both files carry the same content in two serializations:

  • klawiter.ttl — Turtle (RDFS / SKOS)
  • klawiter.vocab.jsonld — JSON-LD

Vocabulary Design

Each bibliographic entry uses multiple vocabularies via JSON-LD @context:

  • schema: Standard fields (name, datePublished, publisher, translator, inLanguage, numberOfPages, etc.)
  • dcterms: Bibliographic citation and provenance
  • klawiter: Domain-specific types, classifications, and source metadata (defined below)

Entry Types

Each entry carries a @type array combining a Schema.org type with a domain-specific klawiter: type:

Domain-Specific Properties

Properties defined in the klawiter: namespace (no Schema.org or Dublin Core equivalent):

PropertyRangeDescription
klawiter:entryType xsd:string Classification key: fiction, essay, poetry, drama, film, correspondence, collected-works, secondary-literature, historical-study, translation, foreword, symposium, dramatic-reading, newspaper, redirect, other
klawiter:timePeriod xsd:string Historical period: pre-zweig (<1881), lifetime (1881–1942), post-wwii (1943–1980), late-20c (1981–2000), contemporary (2001+)
klawiter:categories @set of xsd:string MediaWiki categories from the original bibliography wiki
klawiter:mainCategory xsd:string Primary category used for entry type classification
klawiter:originalTitle xsd:string Original-language title (when entry title differs, e.g. for translations)
klawiter:languageCode xsd:string ISO 639-1 language code (de, en, fr, zh, etc.)
klawiter:allYears @set of xsd:integer All years mentioned in the entry (when multiple editions/reprints are listed)
klawiter:allLocations @set of xsd:string All publication locations when multiple are mentioned
klawiter:locationSameAs @id (IRI) Wikidata URI of the primary publication location (e.g. http://www.wikidata.org/entity/Q90 for Paris). The place is taken from the source and reconciled against Wikidata; a dedicated property, not schema:sameAs, which would conflate the work with the place.
klawiter:reprints @set of xsd:string References to reprint editions
klawiter:contentItems @list of xsd:string Table of contents for collected works (ordered)
klawiter:sourcePageId xsd:integer Original MediaWiki page ID (provenance)
klawiter:sourceTextId xsd:integer MediaWiki text revision ID (provenance)
klawiter:sourceBlobId xsd:integer BLOB file number (0–7) containing the source text
klawiter:pageNamespace xsd:integer MediaWiki namespace (0=main, 14=category, etc.)
klawiter:isRedirect xsd:boolean True if entry is a redirect alias
klawiter:redirectTarget xsd:string Title of the target entry for redirects

Alignment Notes

Stefan Zweig Digital

The Stefan Zweig Digital project at the Stefan Zweig Centre Salzburg (University of Salzburg) uses CIDOC-CRM for cultural heritage modeling. A future alignment between this vocabulary and CIDOC-CRM / LRMoo is planned as a separate research project to enable cross-project linked data queries.

Wikidata

Stefan Zweig is identified as Q78491 in Wikidata. This identifier is used as author metadata in the JSON-LD output. Reconciliation of individual entries against external authority systems is out of scope for this project (see Data Integrity Principle).
